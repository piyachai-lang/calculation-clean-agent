# FK Calculator

เว็บแอพสำหรับคำนวณสารดับเพลิง FK-5-1-12 / Novec 1230 และเลือกขนาดกับจำนวนถัง ใช้งานได้บนโทรศัพท์ผ่านเบราว์เซอร์

## ใช้งาน

กรอกขนาดห้อง Class อุณหภูมิ ปริมาณเผื่อ และเปอร์เซ็นต์เติมสูงสุด แล้วกดคำนวณ

- สูตรสารอ้างอิง Sheet FK จาก DesignFireSup-20261002.xlsx
- ขนาดและช่วงเติมถังอ้างอิงตารางที่เจ้าของโครงการให้มา
- เลือกจำนวนถังน้อยที่สุด แล้วเลือกขนาดเล็กที่สุดที่รองรับช่วงเติม
- ค่าเริ่มต้นเติมได้สูงสุด 80% ของค่าสูงสุดในตาราง ปรับได้
- บันทึกข้อมูลเฉพาะในเบราว์เซอร์ของผู้ใช้เมื่อรองรับ ไม่มีการส่งข้อมูลห้องไปยังเซิร์ฟเวอร์
- ปุ่มล้างข้อมูลล้างทุกช่อง ผลคำนวณ และข้อมูลที่บันทึกไว้

## GitHub Pages

Settings → Pages → Deploy from a branch → main → /(root) → Save

ไฟล์เว็บไซต์คือ `index.html`, `calc.js`, `app.js` และ `.nojekyll`

เปิดเว็บไซต์ผ่าน Safari บน iPhone ไม่ใช่หน้าตัวอย่างไฟล์ HTML ในแอป Files หรือแอปแชต

การออกแบบระบบและการเลือกถังต้องตรวจสอบข้อกำหนดผู้ผลิตและมาตรฐานของโครงการ
